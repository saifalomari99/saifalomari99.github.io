## Overview

This repository is the complete record of my undergraduate FPGA work on the Nexys A7-100T (Artix-7). The two strongest projects, the [SoC dynamic game](/projects/fpga-soc-dynamic-game/) and the [custom MMIO cores](/projects/fpga-mmio-peripheral-cores/), have their own pages; this page covers the full set.

## Verilog projects (Spring 2023)

Every design has its own constraints file and was synthesized and run on the board.

1. **Full adder** and 4-bit ripple-carry adder, with a simulation testbench
2. **Seven-segment decoder**
3. **Counter on the seven-segment display** with a clock divider
4. **Persistence-of-vision display** multiplexing four digits at 400 Hz
5. **Digital clock** (minutes and seconds)
6. **Sound generator** playing a 48-note tune from a note and duration ROM
7. **Alarm clock** with settable alarm across eight digits and a song on match
8. **FSM debouncing circuit** with a Moore edge detector driving an up/down counter
9. **FSMD bit-counting circuit** separating control and datapath registers
10. **Serial data transmission** with a parallel-to-serial shift register and odd-parity generator
11. **FSM questions game**: a five-question arithmetic quiz with seven-segment text and win/lose audio

## SystemVerilog projects (Spring 2024)

1. **Barrel shifter**: parameterized left/right shifters, a multi-function version, and a bit-reverser variant, each with testbenches
2. **Programmable square-wave generator** with adjustable on and off times
3. **Early debouncer** FSM
4. **ROM-based temperature conversion**: block-RAM lookup tables initialized from memory files, binary-to-BCD, multiplexed display
5. **Asymmetric FIFO**: 16-bit write port, 8-bit read port, with a controller and register file
6. **SoC chasing LED** with switch-selected speed and UART status output
7. **SoC blinking-LED core**: a custom memory-mapped core (see the cores page)
8. **SoC ADC chasing LED**: XADC reads a potentiometer to set chase speed
9. **SoC PWM spectrum display**: potentiometer sets a tri-color LED color through PWM, with voltage on the display
10. **SoC tap detection**: reads the on-board ADXL362 accelerometer over SPI and lights LEDs by tap magnitude
11. **SoC Pmod rotary-encoder control**: a custom encoder core driving RGB intensity (see the cores page)
12. **SoC keyboard chasing LED**: PS/2 scan-code decoding sets speed and pause
13. **VGA square generator** at 640x480
14. **SoC final project**: the dynamic VGA game (see its page)

## What this series shows

- RTL fundamentals: combinational and sequential logic, clock division, multiplexing, shift registers, parity
- Control design: Moore and Mealy FSMs, FSMD partitioning, debouncing, edge detection
- Memory and datapaths: block-RAM ROMs, FIFOs with asymmetric ports, parameterized modules
- SoC integration: memory-mapped peripherals, custom cores, processor drivers, and application firmware
- Board-level bring-up: constraints, Pmod wiring, ADC, SPI and PS/2 peripherals, VGA timing

## My contribution

All projects are individual coursework. The Verilog set is entirely my own RTL. The SystemVerilog SoC projects follow Pong Chu's textbook framework; my work there is the custom cores, the application firmware, and the system integration, as noted on the individual pages.
